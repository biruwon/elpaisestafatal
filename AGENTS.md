# Working preferences

- Respond in English.
- For implementation requests, commit and push changes to `main` by default.
- Stage only files relevant to the current task.
- Preserve unrelated changes from parallel chats.

## Claim response quality

- Do not add canned responses keyed to one exact claim or wording. Extend reusable semantic interpretation, evidence selection, and answer composition for the claim family instead.
- Test paraphrases that should use the same evidence and nearby claims that must not cross-route.
- Keep source, period, population, denominator, and scope limitations explicit; never invent a numeric answer when the available evidence does not measure it.
